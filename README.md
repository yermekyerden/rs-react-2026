# Character Explorer

Rick and Morty character explorer migrated to Next.js App Router.

## Stack

- Next.js
- React
- TypeScript
- next-intl
- Tailwind CSS
- Vitest
- React Testing Library

## Runtime

Recommended runtime: Node.js 22.

## Scripts

```bash
npm ci
npm run dev
npm run lint
npm run test
npm run test:coverage
npm run build
```
